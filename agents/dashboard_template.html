Connect WordPress

1
Create an application password
WordPress admin → Users → Profile → Application Passwords → name it Researcher-agents → Add New. Copy the password shown (spaces are fine).
2
Add three secrets in the repo (Settings → Secrets and variables → Actions):
WP_URL = your site address, no trailing slash
WP_USER = the WordPress username
WP_APP_PASSWORD = the password from step 1
Open the secrets page ↗
If Application Passwords do not appear, the site needs HTTPS and no security plugin may block the REST API. Claude never publishes by itself: you choose how articles arrive above.

Work with Claude by hand (GitHub connector)


No server needed. GitHub has its own MCP server and it works with any Claude account.


1
Make a GitHub token. GitHub → Settings → Developer settings → Fine-grained tokens. Repository: this repo only. Permissions: Contents and Actions = Read and write.
Open token page ↗


2
Add the connector. claude.ai or Desktop: Settings → Connectors → Add custom connector:
https://api.githubcopilot.com/mcp/
Claude Code (replace YOUR_TOKEN):
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ --header "Authorization: Bearer YOUR_TOKEN"


3
Tell Claude to start.
