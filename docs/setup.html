Overview

  1. GitHub collects news every few hours and writes one brief per celebrity per batch.
  2. A GitHub Action asks Claude (or Codex as a fallback) to write one original article per brief and saves it in articles/.
  3. GitHub sends the article to WordPress as pending, draft or published (set in config.json).

Secrets needed: CLAUDE_CODE_OAUTH_TOKEN, WP_URL, WP_USER, WP_APP_PASSWORD. Optional: CLAUDE_CODE_OAUTH_TOKEN_2, _3, OPENAI_API_KEY.

Secrets page: github.com/MirzaNumanBaig/Researcher-agents/settings/secrets/actions

1. Get the Claude token (online, no computer needed)

There is no page on claude.ai or the Anthropic console that shows this token. It only comes from the command claude setup-token. A GitHub Codespace gives you a terminal in the browser.
  1. Open the repo, click Code → Codespaces → Create codespace on main.
  2. In the terminal at the bottom, run: 
    npm install -g @anthropic-ai/claude-code
claude setup-token
  3. Open the login link it prints, sign in to the Claude account that should do the writing, approve.
  4. If it shows a code, paste the code into the terminal.
  5. It prints a token starting with sk-ant-oat01-. Copy it right away. It is shown only once.
  6. Go to the secrets page → New repository secret. Name: CLAUDE_CODE_OAUTH_TOKEN. Paste the token. Save.
  7. Delete the Codespace at github.com/codespaces (… → Delete).

A second Claude account: repeat while signed in to that account and name the secret CLAUDE_CODE_OAUTH_TOKEN_2 (third: _3). When one hits its limit, the next takes over.

Let Cowork do it

You must be signed in to GitHub (with settings access to the repo) and to the right Claude account in the browser Cowork uses. You may have to approve the Claude login yourself. Paste this to Cowork:

Task: create a Claude Code long-lived auth token and save it as a GitHub Actions secret. Do not show the token in chat or save it to any file.

1. Check that Claude Code is installed on this computer. If it isn't, install it with: npm install -g @anthropic-ai/claude-code (Node.js is needed; install Node.js LTS first if missing).
2. Open a terminal and run: claude setup-token
   It opens a browser login. Sign in to the Claude account I'm using now and approve. If it asks for a code, paste the code back into the terminal.
3. The terminal prints a token that starts with sk-ant-oat01-. Copy it from the terminal. It is shown only once.
4. In my browser (already signed in to GitHub) open:
   https://github.com/MirzaNumanBaig/Researcher-agents/settings/secrets/actions
   Click "New repository secret". Name: CLAUDE_CODE_OAUTH_TOKEN. Secret: paste the token. Click "Add secret".
   If it already exists, use "Update" and replace the value.
5. Clear the token from the clipboard and terminal history.
6. Tell me only "done" or what failed. Never print or repeat the token.

For a second account (optional): sign out of Claude, repeat steps 2 to 4 on the other account, and name the secret CLAUDE_CODE_OAUTH_TOKEN_2. A third account uses _3.

Alternative: Anthropic API key

Create a key at console.anthropic.com → API Keys. It is pay-per-use and does not use your Claude plan. The workflow currently reads only the OAuth token, so ask Claude to change the workflow before using a key.

2. WordPress (moduscarry.com)

  1. WP_URL is already added (e.g. https://moduscarry.com, no trailing slash).
  2. In WordPress admin, create a user with the Editor or Author role (or use your own).
  3. Go to Users → Profile → Application Passwords, type a name such as "GitHub", click Add New Application Password, and copy the password shown (spaces are fine).
  4. Add two more secrets: WP_USER (the username) and WP_APP_PASSWORD (the application password).

If Application Passwords do not appear, the site must use HTTPS and no security plugin may block the REST API.

How articles arrive: wp_default_status in config.json is pending (review in WordPress). Use draft or publish to change it.

3. First test run

  1. Open Actions → Write articles → Run workflow.
  2. Check that files appear in articles/ and that pending posts appear in WordPress.
  3. If a step fails, open the failed run, copy the error, and give it to Claude.

Switching Claude accounts or AI tools

  • Change account: replace the secret with a token created while signed in to the new account.
  • Add backup accounts with the _2 and _3 secrets.
  • Use ChatGPT/Codex as the last fallback: add OPENAI_API_KEY.
  • Any AI can also write by hand: give it prompts/article.md and one file from briefs/.
